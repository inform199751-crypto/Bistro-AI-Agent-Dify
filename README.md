# 📌 專案概述：基於大語言模型之餐飲營運數位轉型優化實作

本專案針對餐飲服務業（餐酒館 Bistro）勞動力短缺、新進人員教育訓練成本高之痛點，利用 No-Code（免程式碼）AI 開發平台 Dify，編排出一款具備「確定性工作流」與「知識庫檢索（RAG）」的虛擬侍酒與智能客服 AI Agent 系統。

旨在證明非資訊背景人員，亦能透過商務邏輯與痛點驅動思維，快速為傳統實體產業部署企業級的 AI 自動化解決方案。

---

# 🛠️ 使用技術與工具
- **開發平台**：Dify.ai (Workflow 聊天流編排模式)
- **核心模型**：OpenAI GPT-4o-mini
- **架構技術**：提示詞工程 (Prompt Engineering)、結構化工作流控制、RAG 知識庫檢索

---

# 💡 核心功能與實作邏輯

1. **優雅高情商客訴處理**：透過 SYSTEM 系統提示詞調校，賦予 AI 具備餐酒館「微醺、專業、優雅」的人格特質，能自動消化並誠懇回應顧客的 Google 負評與客訴。
2. **確定性侍酒師推薦（防幻覺）**：將官方特調酒水、特色主食菜單（含價格與風味描述）直接嵌入系統，限制大模型不得捏造未販售之商品，精準進行客製化餐酒搭推薦。
3. **複合型商務場景應對**：利用工作流控制邏輯，讓系統能即時、不間斷地精準回覆「店內低消、自備酒水開瓶費、營業時間」等硬性店務規則查詢。

# 📂 開源部署說明
本專案已在 GitHub 開源分享。任何人只要下載本專案中的大腦設定檔（`.yml` 檔案），並重新匯入至個人的 Dify 帳號中，即可 1 秒複製並部署出完全一樣的餐酒館 AI 智能助理系統。
